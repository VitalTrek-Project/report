## Capítulo III: Requirements Specification

### 3.1. User Stories

A continuación se presenta el conjunto completo de Epics, User Stories, Landing Page Stories y Technical Stories identificadas para VitalTrek. Todas las historias se redactan en tiempo presente, tercera persona, sin referencia a detalles de interfaz de usuario, con criterios de aceptación comprobables siguiendo la estructura Gherkin (Given-When-Then).

| Epic / Story ID | Título | Descripción | Criterios de Aceptación | Relacionado con (Epic ID) |
|---|---|---|---|---|
| EP01 | Landing Page | Agrupa las funcionalidades del sitio web estático que comunica la propuesta de valor de VitalTrek a los visitantes de cada segmento objetivo. | — | — |

| US-L09 | Contactar al equipo | Como visitante, quiero contactar al equipo de VitalTrek para resolver dudas relacionadas con la plataforma. | **Escenario 1: Mensaje enviado correctamente**<br>Given que el visitante proporciona información válida en el formulario de contacto<br>When envía la solicitud<br>Then el sistema registra correctamente el mensaje y retorna confirmación de recepción<br><br>**Escenario 2: Datos inválidos**<br>Given que el visitante ingresa información con formato incorrecto<br>When envía el formulario de contacto<br>Then el sistema retorna un error indicando los campos con formato inválido | EP01 |
